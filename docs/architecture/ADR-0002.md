# ADR-0002 — First relational slice (P06–P07)
Accepted foundation PR #1 was green on head 551d18a5a507aaabf15d5ee6130c7f08a7239950 (Core 45851610712, Release 45851610482); physical targets still unverified.
Core has no EF dependency. Infrastructure references Core and owns the SQLite provider/mapping. Desktop references Infrastructure only as composition root. Tests reference the layers. Add application services only when there is an actual use case.
Use stable Microsoft.EntityFrameworkCore.Sqlite 11.0.0 (https://www.nuget.org/packages/Microsoft.EntityFrameworkCore.Sqlite/11.0.0); exercise its native SQLite library in both published architectures. No persistent production database is opened in this PR. EnsureCreated is restricted to tests and the isolated in-memory architecture probe; production must use versioned migrations in P08. SQLite foreign keys explicitly enabled on connections; no credentials or customer secrets stored yet. Do not introduce password persistence before P09.
