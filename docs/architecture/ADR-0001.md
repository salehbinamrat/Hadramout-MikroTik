# Provisional technology decision
Evaluate stable SDK 11.0.100, C# 15, native WPF. Modular monolith; add modules only when needed. PowerShell/YAML and Inno Setup only for packaging/CI, not runtime. xUnit baseline. No production packages yet.
.NET 11 raises CPU requirements: https://learn.microsoft.com/dotnet/core/compatibility/jit/11/minimum-hardware-requirements . Hosted x86 process on x64 Windows is not proof of native 32-bit OS compatibility. If target devices fail, evaluate .NET 10 LTS; do not silently drop x86.
