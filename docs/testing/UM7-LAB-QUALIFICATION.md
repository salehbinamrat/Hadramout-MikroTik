## P17b.2c — Non-rearmable local claim
Schema v14 retains a one-shot claim (DispatchStarted=2, Indeterminate=3), keyed to the immutable secret and intent. Under one immediate SQLite transaction reject existing claims, verify and decrypt the scoped secret, insert the durable claim and commit before returning the disposable lease. Missing/invalid secret does not commit a claim. A crash after commit leaves DispatchStarted; neither state can be deleted, replaced, reset or restored from an older snapshot. Eight concurrent attempts must yield one winner. No acknowledgement state until qualified wire receipt and retained evidence are designed. This is a local qualification primitive, not permission to send. No remote write path or actual lab run.
