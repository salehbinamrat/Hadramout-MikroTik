# P10d — Restored credential inspection and explicit re-entry

After a trusted encrypted backup is authenticated and restored into an isolated candidate, inspect all router IDs without returning any secret or changing the database. AvailableLocally means both DPAPI/AES envelopes can be decrypted by the current Windows user, not that the router accepts the credentials. Missing means no stored credential row. Unavailable means local decryption/format verification failed; it is not proof that the file came from another device, because corruption and other DPAPI failures are indistinguishable. The report exposes only IDs and states; it never logs credentials, ciphertext, or exception payloads. Unexpected database and I/O failures propagate, not converted to missing. Blob length/type checks precede allocation.

Chosen recovery policy: retain original encrypted backup and all router definitions. No automatic deletion/reset/export of credentials. A user explicitly re-enters credentials for each unavailable router, with both envelopes encrypted to the current user. Re-entry is allowed only for an existing unavailable record; no overwriting a readable credential or creating a record for an unknown router via this path. A single immediate transaction checks availability, replaces the pair and appends an audit event. Missing credentials can later be configured through the normal approved UI flow. Reinspect after re-entry. No claim of successful network login; actual credential verification is future transport work.

The API accepts a trusted candidate path selected by the caller; no live activation or role authorization UI is exposed in this phase. Future activation must require explicit user confirmation, isolation from concurrent writers, pre-activation safety backup, retention and current audit history preservation; no raw credential export. Real cross-account and cross-device DPAPI tests remain pending; synthetic corrupt envelopes exercise the same unavailable recovery branch, not a real second account. Workspace ACL and crash cleanup remain pending.
